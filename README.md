## 🌟 Tính năng chính
- **Lịch khách linh hoạt**: Xem lịch theo Tháng, Tuần (7 ngày & phân bổ khung giờ 06:00 - 18:00), Ngày chi tiết.
- **Quản lý tiền cọc & công nợ**: Tự động tính tiền cọc, số tiền còn lại và tổng giá trị đơn; hỗ trợ thu thêm & thanh toán đủ 1-click.
- **Danh sách khách hàng**: Phân loại theo nhóm Cô dâu, Ăn hỏi, Tiệc, Chụp ảnh; tìm kiếm thông minh theo SĐT, tên, dịch vụ.
- **Hóa đơn & Phiếu thu**: Mẫu phiếu in xác nhận đặt cọc và dịch vụ chuẩn in ấn.
- **Thông báo & Nhắc lịch tự động**: Mẫu tin nhắn SMS / Zalo gửi khách, nhắc cọc và thu nợ chống bùng lịch.
- **Sao lưu & Đồng bộ**: Xuất file Excel / CSV (chuẩn tiếng Việt UTF-8 BOM), backup dữ liệu JSON, đồng bộ trực tiếp file `customers.json`.
- **Responsive đa nền tảng**: Tự động tối ưu giao diện Web Desktop Dashboard & Mobile App.

## 🛠️ Công nghệ sử dụng
- React 19
- Vite
- Tailwind CSS v4
- Lucide React
- Node JSON File Persistence API

## 🚀 Cài đặt & Chạy ứng dụng

```bash
npm install
npm run dev
```
